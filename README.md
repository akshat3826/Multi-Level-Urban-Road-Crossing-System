## 📁 Model Files
**Main Blender File:** `Multi-Level-Road-Crossing-System.blend`  
**Blender Version:** 3.4+ recommended  
**Scale:** Real-world metric (1 Blender unit = 1 meter)

## 🎯 Model Overview

This 3D model serves as an engineering proof-of-concept for our multi-level intersection system, focusing on functional validation rather than visual polish.

### Core Features Demonstrated:
- Three-level vertical separation (elevated, ground, underground)
- 2.86° ramp gradients for smooth transitions
- 4.5m deep underground tunnel with dedicated cycle lanes
- Real-world engineering proportions and standards

## 🔧 Technical Specifications

### Structural Elements
**Elevated Road:**

- Lane Width: 7.0 meters
- Ramp Gradient: 2.86°
- Slab Thickness: 1.5 meters

**Underground Tunnel:**

- Depth: 4.5 meters
- Cycle Lanes: 4.0 meters width
- Pedestrian Paths: 1.0 meters width
· Wall Thickness: 0.3 meters

**Ground Level:**

- Standard road specifications
- Turning lane configurations
- Coordinated signal positioning


## 🖥️ Navigation Guide

### Getting Started
1. Download the `.blend` file
2. Open in Blender 3.4+
3. Use pre-configured cameras for different perspectives

### Available Viewpoints:
- **Overview Camera** - Complete system layout
- **Elevated Level** - North-south traffic perspective
- **Ground Level** - East-west traffic flow
- **Underground Level** - Pedestrian and cyclist experience
